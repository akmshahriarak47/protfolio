# Product Specification

## Surface Type
**Product & Brand Hybrid**: Modern developer experience portfolio & tool hub.

## Target Audience
- Technical buyers, software engineers, and discerning product designers.
- Users who value high craftsmanship, micro-animations, speed, and clean typography.

## Product Lane & Value Proposition
- **Lane**: Modern DevTech & Creative Engineering Showcase.
- **Core Value**: Fast, beautiful, interactive web experiences powered by modern component registries (KokonutUI, MagicUI, Bklit, shadcn/ui) and hardware-accelerated GSAP motion.

## Voice & Tone
- **Direct & Confident**: Minimal fluff, concise copy, high signal-to-noise ratio.
- **Technical Craftsmanship**: Respects developers' time, provides keyboard shortcuts and code snippets directly.
- **Modern Polish**: Smooth physics-based motion without distraction.

## Anti-References & Bans
- **No generic AI purple/pink mesh gradients**.
- **No nested cards inside cards inside cards**.
- **No pure un-tinted #000000 or #ffffff**.
- **No unprompted em-dash overuse**.
- **No bouncy or dated spring animations** on critical user actions.

## Key Surfaces & Features
1. **Interactive Hero**: Dynamic typography with subtle GSAP particle bursts / glow.
2. **Component Gallery**: Showcase of live interactive widgets (KokonutUI particle buttons, MagicUI visual elements, Bklit charts).
3. **Architecture & Stack Inspector**: Live technical documentation and command references.
